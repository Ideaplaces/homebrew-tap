# IdeaPlaces Homebrew Tap

```bash
brew install --cask ideaplaces/tap/agent-inbox
```

| Cask | What it is |
|------|------------|
| [`agent-inbox`](Casks/agent-inbox.rb) | Native notifications for every Claude Code session that finishes or needs you, across all your machines. [Source](https://github.com/Ideaplaces/agent-inbox) |

Upgrading is `brew upgrade --cask agent-inbox`.
